# Orbit PRO — Real App Starter

A full-stack dating-app starter with:
- Real user registration/login
- Profiles and profile editing
- Discovery/swipe-style matching
- Mutual matches
- Real-time-ready chat API structure
- Reports and blocking
- Safety/content checks
- SQLite database
- Password hashing and JWT authentication
- Responsive mobile-first frontend

## Run locally

Requirements: Node.js 18+

```bash
cd backend
npm install
npm start
```

Then open `http://localhost:3000`.

For development:
```bash
npm run dev
```

This is a production-oriented starter, not a deployed service. For a real public launch, configure HTTPS, a production database, image/object storage, email/phone verification, rate limiting, moderation, backups, and a managed hosting provider.
